Forever Planner

Set up

Add your Battle.net API client in Settings, then add a character by first name and surname. Your client secret is stored only in this browser and is sent only to Battle.net.

What to get next

Most valuable first. Each slot shows the best upgrade within levels of you, and a quicker option you can use now when there is one.
